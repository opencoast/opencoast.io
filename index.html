Who we are

Open Coast started in 2023. Each of us has five to more than ten years in the industry, at companies where systems serve millions of people every day.

Most of what that work teaches never leaves the building. We would rather write it down as code that anyone can read, run and change, and keep doing that for as long as we can.

How we work

  • Built from practice

    Our projects start from problems we have actually run into on the job, not from a wish list.

  • Open by default

    Code, releases and decisions happen in public, so anyone can see how a thing was made and why.

  • Here for the long run

    A small project that stays alive is worth more than a big one left behind. We ship steadily and keep going.
